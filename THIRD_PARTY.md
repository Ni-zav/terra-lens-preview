# Third-party components and imagery

- React and React DOM, MIT license: https://github.com/facebook/react
- Vite, MIT license: https://github.com/vitejs/vite
- Apache ECharts and ZRender, Apache License 2.0: https://github.com/apache/echarts
- Three.js, MIT license: https://github.com/mrdoob/three.js (license reproduced in `vendor/THREE-LICENSE.txt`)
- NASA Blue Marble, 2001 land and shallow-water composite. Image courtesy Reto Stöckli and NASA Earth Observatory, downsampled for the geographic picker: https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/
- NASA POWER monthly API supplies the analysis data, not the Blue Marble imagery: https://power.larc.nasa.gov/docs/services/api/temporal/monthly/

Exact package versions and transitive dependencies are recorded in `package-lock.json`.
